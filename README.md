# Dmitry Andreyanov — AI Agent Systems Architect

> **Prizolov Lab** · Автор: Dm.Andreyanov · Версия: v0.1.0-draft

Dmitry Andreyanov (Дмитрий Андреянов, also known as Dm.Andreyanov) — AI Agent Systems Architect, creator of Agent Genome Mapping™ and Agenomics, an open methodology for measuring the trustworthiness of autonomous AI agents.

**Mission:** making autonomous AI measurable, predictable and governable.

Дмитрий Андреянов — архитектор систем ИИ-агентов, автор Agent Genome Mapping™ и Agenomics, открытой методологии оценки доверия к автономным ИИ-агентам.

## Projects / Проекты

- **[Agenomics](https://github.com/prizolov-lab/agenomics)** — AI agent trust evaluation methodology: predictability and compatibility scoring for autonomous agent personalities. Not related to genomics. ([PyPI](https://pypi.org/project/agenomics/))
- **[Agent Genome Mapping™ (AGM)](https://github.com/prizolov-lab/agent-genome-mapping)** — evolutionary architecture for autonomous AI systems.
- **[Prizolov Agent OS](https://github.com/prizolov-lab/prizolov-agent-os)** — open-source orchestration framework for autonomous AI, built for RAG-driven business automation.
- **[Destination Readiness](https://github.com/prizolov-lab/destination-readiness)** — independent, source-cited methodology for scoring how ready a travel destination is for a specific trip. A separate project, unrelated to Agenomics.
- **[Repo Validator Agent](https://github.com/prizolov-lab/repo_validator_agent)** — AI agent for GitHub repository validation and step-by-step fixing.
